# Noel’i Yeniden Yaz (Christmas Rewrite, Turkish)

A Turkish translation of **Christmas Rewrite**, an Elm puzzle adventure about
the Hale family bookshop, made for a game jam on the theme "time".

This repository is a standalone copy with every piece of on-screen text
translated into Turkish. The game itself (rules, art, sound, code structure)
is unchanged, except that the A–Z shelf order follows the Turkish book titles.

The original English game lives at https://github.com/periyr/Christmas-Rewrite.

## Run it

```
npm install
npm start      # local server
npm run build  # static site in build/
npm test       # elm-test
```
